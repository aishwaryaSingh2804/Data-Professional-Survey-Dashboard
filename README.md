Data Professional Survey Dashboard – Power BI project analyzing 630+ survey responses.

Summary: Cleaned and transformed survey data, built interactive dashboards for salary and satisfaction analysis. Key insights include the predominance of Python users and that salary satisfaction is lowest (avg ~4.3/10). See report for details.

Tech: Power BI, Power Query, Excel.
